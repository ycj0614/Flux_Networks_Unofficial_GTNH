# Flux Networks Unofficial GTNH

**This has nothing with the original!**

- Unofficial [Flux Networks](https://github.com/SonarSonic/Flux-Networks) backport for Minecraft 1.7.10 / Forge 10.13.4.1614
- GTNH Exclusives, only can hold GT5U EU, not RF/AE/IC2 EU.

# Requirement

- GTNH 2.9.0 (GregTech 5 Unofficial 5.09.54.264)
- Java 8 bytecode

# Installation

- Put the .jar file into /mod of your instance.

# Description

- Unlike the original that uses RF as default, flux plug / point uses EU tier and Amperage configuration.
- **Using higher tier or amp even by mistake, would cause adjust machines / cables destroy themselves, just like Greg intended.**
- However flux plug and point itself doesn't self-destruct. It just don't accept higher tier of EU than its config.

# Config

`config/flux_networks.cfg`
- `Enable GT Recipes`(true at default): On default this mod uses gregified recipe. You can turn it off for original recipe.
